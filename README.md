# QuizParty - 聚会问答大冒险

🎮 **在线试玩：https://moonrella.github.io/quizparty/**

一款开源的网页聚会问答游戏，支持本地多人游玩。适合朋友聚会、旅行夜晚等场景，通过投影或大屏幕一起玩耍。

## 功能特色

- **大富翁棋盘** — 掷骰子前进，踩到不同格子触发不同事件
- **问答答题** — 9大主题 × 6个难度，162道预设题目
- **命运转盘** — 双转盘随机抽题，主题+难度组合
- **抢答模式** — 命运格触发全场抢答，主持人判定
- **地产系统** — 买地收租，大富翁经典玩法
- **地图编辑器** — 自定义棋盘布局
- **题库管理** — 可视化添加/编辑/删除题目，支持JSON导入导出
- **自定义主题** — 玩家自己创建题目分类
- **可配置轮数** — 达到设定轮数后金币最多者获胜

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

启动后浏览器打开 http://localhost:5173 即可游玩。

## 技术栈

- React 19 + TypeScript
- Vite 构建工具
- React Router 路由
- LocalStorage 本地存储（无需服务器）

## 部署

构建后的 `dist/` 文件夹可以部署到任何静态托管服务：

- **GitHub Pages** — 免费托管
- **Vercel** — 一键部署
- **Netlify** — 拖拽部署
